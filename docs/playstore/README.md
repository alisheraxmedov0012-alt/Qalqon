# QALQON — Play Store launch artifacts

Ready-to-use launch materials for the Google Play submission. **Nothing here is
submitted, approved, or verified in Play Console.** "Prepared" ≠ "Submitted" ≠ "Approved".

| File | What it is |
|---|---|
| `PRIVACY_POLICY.md` | Final privacy-policy text (code-accurate). Not hosted. |
| `DATA_SAFETY.md` | Data safety answer sheet + per-type technical matrix. |
| `STORE_LISTING.md` | Play-safe title/short/full description (en/uz/ru) + claim↔capability check. |
| `PERMISSION_DISCLOSURES.md` | Camera/Accessibility/Usage Access/Overlay/FGS disclosures + declaration packs. |
| `SUBSCRIPTION_DISCLOSURE.md` | Premium subscription disclosure and Play Console config steps. |
| `ACCOUNT_DELETION.md` | In-app deletion (implemented) + external web resource (missing). |
| `SUPPORT.md` | Support/contact requirements (email/URL currently MISSING). |
| `SCREENSHOTS_PLAN.md` | Store-asset shot list and content rules. |
| `THIRD_PARTY_LICENSES.md` | Dependency/license inventory (legal review required). |
| `PLAY_CONSOLE_CHECKLIST.md` | Every Console item as READY / MISSING / NOT VERIFIED. |

The detailed working appendices (older numbering) remain under `docs/STAGE8_*.md`
(privacy hosting, declarations, reviewer access, store assets, subscription setup) and
`docs/STAGE11_PLAY_STORE_LAUNCH_READINESS.md` (the Stage 11 audit report).

**Manual items still required before submission:** public HTTPS privacy-policy and
account-deletion URLs, support email, store graphics, release signing/upload key,
Play Console declarations (Data safety, Accessibility, FGS, sensitive permissions),
subscription product/base-plan/trial/price, license testers, and a real purchase test.
